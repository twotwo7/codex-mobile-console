Real use cases

不再只是远控会话，而是管理 AI 运行环境。

从一页中枢进入秘书任务、服务器资源、项目会话和审计恢复，再深入处理具体工作。

Queue

灵感来了先排队，当前任务结束后自动接上。

开会、通勤、吃饭时想到补充需求，直接放进队列；需要调整顺序时置顶或编辑。

Runtime

状态不对时，一眼看到进程、队列和浏览器缓存。

右上角状态、运行时面板、停止入口、恢复检测放在一起，避免任务完成后还误以为仍在运行。

Skills

常用能力沉淀成 Skill，输入时可以快速带入。

Skill 管理异步扫描、本地缓存、变更提示，主聊天流程保持轻量稳定。

Feature map

围绕自托管 AI 运维闭环组织，而不是再做一个聊天客户端。

01 统一中枢

服务器健康、秘书任务、项目会话、审计恢复和升级入口集中在同一个工作面。

02 长期专家秘书

按计划生成重点、继续未完成任务、主动学习并记录证据，同时保留可见总停止。

03 运维与恢复

查看运行时、磁盘和版本，安全停止任务，完成备份、恢复、升级与回滚。

04 多端私有入口

适合 VPS、NAS、家用主机或远程开发机，用手机、平板和桌面访问同一套私有运行环境。

Install and update

OSS 安装，后续自动更新。

适合国内服务器：复制命令到服务器执行，安装完成后把服务放到自己的 HTTPS 域名后面即可。

01 复制安装命令

curl -fsSL https://welcome.ai.hehao.pro/install.sh | bash

02 自动完成部署

脚本会从 OSS 获取最新版本，安装依赖，创建 systemd 服务，并绑定到 127.0.0.1:7072。

03 默认自动更新

安装器会写入 OSS 更新源。后续有新版本时，控制台默认自动检查并安全升级。

04 需要时可关闭

如果你更想手动控制版本，可以在控制台设置里关闭自动更新。
